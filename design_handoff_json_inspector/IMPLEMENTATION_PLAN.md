# План реализации для Claude Code

Пошаговый план внедрения редизайна в `Jurager/json-inspector` (ветка `main`). Каждый шаг самодостаточен: после него приложение собирается и работает. Работайте строго по одному шагу за запрос.

Спецификация дизайна — `design_handoff_json_inspector/README.md`. Прототип — `design_handoff_json_inspector/JSON Inspector - Зоны и редизайн.dc.html` (открыть в браузере).

Общие правила для всех шагов (стоит повторять в каждом промпте):

- Новых цветов не вводить. Только переменные из `frontend/src/style.css`. Тёмная тема обязана работать — она уже описана в `@media (prefers-color-scheme: dark)`.
- Стили — как в проекте: `<style scoped>` + `@reference "../style.css"` + `@apply`, общие классы — в `style.css`.
- Иконки — только через `Icon.vue` (lucide, `stroke-width: 1.5`). Нужна новая — добавить в карту `ICONS`, а не рисовать SVG вручную.
- Существующие утилиты переиспользовать: `statusClass`, `methodClass`, `formatBytes`, `formatDuration`, `decodeUrl`, `tryParseJson`, `highlightJson` из `lib/json.ts`; `shortcut()` из `lib/platform.ts`; `copyToClipboard`, `exportRequest` из `lib/export.ts`.
- Комментарии в коде — в стиле проекта: объясняют «почему», а не «что».
- Перед применением показать diff. После шага: `make build`, затем визуальная проверка против прототипа.

3. **Тесты/схема** — валидация документа по JSON:API: обязательные поля, дубли `type/id`, битые ссылки в `relationships`, `included` без ссылок на него. Список проверок: точка-индикатор (`--green`/`--orange`/`--red`) + текст + путь моно. Логику положить в `lib/schema.ts` (файл уже есть).

**Приёмка:** каждая вкладка добавляется отдельным коммитом; порядок вкладок не меняется; вкладка не показывается, когда для неё нет данных.

## Шаг 9 — состояние перехвата из расширения (опционально, но закрывает статус-бар)

**Файлы:** `internal/bridge/protocol.go`, `internal/bridge/server.go`, `app.go`, `extension/background.js`, `frontend/src/stores/requests.ts`.

**Что сделать:** добавить в wire-формат второй тип сообщения рядом с `CapturedRequest`:

```go
type CaptureState struct {
    Type      string `json:"type"` // "state"
    Recording bool   `json:"recording"`
    Tabs      int    `json:"tabs"`
    Browser   string `json:"browser"`
}
```

`server.go` сейчас пропускает всё, где `Type != "request"` — разобрать оба типа и вызвать соответствующий хендлер. `app.go` эмитит `EventsEmit(ctx, "capture-state", s)`. `background.js` отправляет состояние при подключении, при включении и выключении перехвата вкладки и при закрытии вкладки. Фронт подписывается и кладёт в `store.capture` — заглушку с таймаутом из шага 1 убрать. Дополнительно: при обрыве сокета ставить `connected: false`, чтобы статус-бар не врал.
