# Handoff 2: переменные окружения + редизайн браузерного расширения

## Что это

Второй пакет для `Jurager/json-inspector` (Go + Wails v2 + Vue 3 + TS, ветка `main`). Он продолжает первый (`README.md`, зоны 1–7) и закрывает две темы:

1. **Окружения и переменные** в десктопном приложении — зона 1 (титлбар) по правилам первого пакета.
2. **Редизайн попапа расширения** — `extension/popup/*`.

Дизайн-референс: `JSON Inspector - Зоны и редизайн.dc.html`, блоки **04 · Расширение** и **05 · Окружения**. Это прототип, не исходник: берите состав, порядок, плотность и значения, реализуйте средствами проекта (Vue 3 SFC + Tailwind v4 `@apply` + переменные из `frontend/src/style.css`; попап — обычные HTML/CSS/JS, как сейчас).

Новых цветовых токенов не вводится. Тёмная тема должна работать.

# Часть 1. Окружения и переменные

## Модель

```ts
type VarKind = 'text' | 'secret'

interface Variable {
  id: string
  name: string            // [A-Za-z_][A-Za-z0-9_]*
  value: string           // для secret в сторе не хранится, см. «Секреты»
  kind: VarKind
  enabled: boolean
}

interface Environment {
  id: string
  name: string            // «Local · dev», «Stage», «Prod»
  color?: 'green' | 'orange' | 'red' | 'purple'   // точка в чипе
  readonly: boolean       // Prod по умолчанию true
  vars: Variable[]
}

interface EnvState {
  environments: Environment[]
  globals: Variable[]      // «Глобальные» — общие для всех окружений
  activeId: string | null  // null = «Без окружения»
}
```

Окружение — свойство **окна**, не запроса. Смена окружения не меняет сохранённые запросы, меняются только подстановки.

## Порядок разрешения

`запрос → окружение → глобальные`. Первое найденное значение выигрывает. Выключенная (`enabled: false`) переменная в разрешении не участвует. Не найденная переменная — ошибка, а не пустая строка.

Где подставляем: URL, значения и имена параметров, заголовки, тело, поля auth. Синтаксис — `{{name}}`, двойные фигурные скобки, пробелы внутри допустимы (`{{ name }}`). Экранирование — `\{{`.

#### Имя окружения: создание и переименование

Паттерн Finder, без отдельных диалогов:
- `+` в подвале создаёт окружение сразу строкой в режиме ввода, имя по умолчанию «Новое окружение» выделено целиком;
- переименование — двойной клик по имени или Enter на выделенной строке; переименовать можно и активное окружение;
- Enter и клик вне сохраняют, Esc отменяет, Tab переходит на следующую строку в режиме ввода;
- пустое имя и дубликат не сохраняются: рамка инпута краснеет (`rgba(255,59,48,.45)`), фокус остаётся в поле;
- геометрия инпута обязана повторять ритм строки: строка всё те же 30px, инпут 26px, `box-sizing: border-box`, радиус 6px, рамка `--accent` + `0 0 0 3px var(--accent-soft)`, `padding: 0 7px`, `outline: none`. Текст в инпуте стоит ровно там же, где имя в соседних строках (в прототипе это сделано отрицательным `margin-left`), строка не прыгает по высоте при входе в режим ввода.

Имя окружения — свободный текст («Local · dev», «Stage · qa»), ограничение — 40 символов. Переименование меняет подпись в чипе титлбара, в меню, в статус-баре и в тексте ошибки о ненайденной переменной; `id` окружения не меняется, секреты в связке ключей не переезжают.

**Правая колонка**:
- тулбар 40px: только фильтр по имени (28px, радиус 7px, фон `rgba(0,0,0,.045)`, иконка `search` 12px, без рамки, `max-width: 260px`). Глобальной кнопки «Показать секреты» **нет** — раскрытие точечное, глазом в строке;
- шапка таблицы 30px: колонки `200px | 1fr | 96px | 34px` — «Переменная», «Значение», «Тип», действие. Моно 10px uppercase `--text-tertiary`, `border-bottom: 1px solid var(--border)`;
- строки 38px, `border-bottom: 1px solid rgba(0,0,0,.06)`, hover `rgba(0,0,0,.025)`. Имя и значение — моно 12.5px, ellipsis; правка по месту (клик → inline input, Enter — сохранить, Esc — отменить, Tab — следующая ячейка);
- колонка «Тип» — бейдж 10px/600, радиус 4px: «текст» (`rgba(0,0,0,.05)` / `--text-secondary`), «секрет» (`--orange-soft` / #b26a00), «глобальная» (`color-mix(--purple 13%)` / #7d3bb0), «перекрыта» (`rgba(0,0,0,.05)` / `--text-tertiary`);
- **секрет раскрывается построчно**: в ячейке значения сразу за точками стоит кнопка-глаз 20×20, радиус 5px, иконка `eye` 13px `--text-tertiary`, hover — `rgba(0,0,0,.06)` и `--text`. Клик показывает значение этой одной переменной (иконка меняется на `eye-off`), повторный — скрывает; при закрытии листа все секреты снова скрыты. Общей кнопки «Показать всё» нет;
- последняя строка собственных переменных — «+ Новая переменная» (`--text-tertiary`, иконка `plus` 13px), создаёт пустую строку с фокусом в имени;
- подвал 34px, `border-top`: «Секреты хранятся в связке ключей macOS и не попадают в экспорт коллекции».

#### Глобальные внутри окружения

Глобальные переменные видны **прямо в таблице любого окружения**, отдельной группой под собственными — чтобы не искать их во втором списке и не гадать, откуда взялась `locale`.

- заголовок группы 30px, фон `--bg-inset`: «Наследуется из глобальных» (моно 10px uppercase) + счётчик, справа пояснение «действуют во всех окружениях» 11.5px `--text-tertiary`;
- строки группы — тот же грид, фон `rgba(175,82,222,.03)`, hover `rgba(175,82,222,.07)`; перед именем — иконка наследования (`corner-down-right`) 11px цвета #7d3bb0, имя и значение — `--text-secondary`, бейдж «глобальная», в колонке действия — карандаш (правка самой глобальной переменной, она подействует везде);
- строки группы не удаляются из окружения — только из раздела «Глобальные» слева.

**Переопределение делается в обычном списке**, отдельной команды «переопределить» нет: пользователь заводит в окружении переменную с тем же именем, и она выигрывает по порядку разрешения. В этот момент строка глобальной ниже:
- зачёркивается (имя и значение, `line-through`, `--text-tertiary`), иконка наследования блекнет;
- меняет бейдж на серый «перекрыта»;
- по наведению даёт `title`: «Перекрыта переменной окружения».

Удалил свою строку — глобальная снова активна, без подтверждений.

**Поведение:**
- переименование переменной не переписывает токены в запросах — старый токен становится неизвестным и подсвечивается красным;
- дубликат имени в пределах окружения запрещён: поле имени краснеет, сохранение блокируется;
- read-only окружение: ячейки не редактируются, в тулбаре справа появляется кнопка «Разблокировать» 26px, после неё окружение правится до закрытия листа;
- удаление окружения — подтверждение, если на его переменные ссылается хотя бы один сохранённый запрос.

### 5. Статус-бар (зона 7)

Слева уже показывается активное окружение. Добавляется: при `activeId === null` — «Без окружения»; при неизвестных переменных в текущем запросе — «1 переменная не найдена» цветом #d1372c.

## Секреты

- `kind: 'secret'` — значение не хранится в `localStorage` и не попадает в экспорт коллекции/запроса (`lib/export.ts`).
- Хранилище — связка ключей: Go-сторона, сервис `json-inspector`, аккаунт `env:<envId>:<varName>`. Методы, экспортируемые в фронт через Wails: `SecretSet(envId, name, value)`, `SecretGet(envId, name)`, `SecretDelete(envId, name)`, `SecretList(envId)`.
- Если связка ключей недоступна (Linux без бэкенда), секреты живут только в памяти сессии, а в подвале листа выводится: «Связка ключей недоступна — секреты не сохранятся после выхода».
- В логах, тултипах и превью запроса значение секрета заменяется на `••••`.

## Импорт .env

Кнопка «Импорт .env» — диалог выбора файла. Разбор: строки `KEY=value`, `#` — комментарий, кавычки снимаются, `export ` в начале игнорируется. Имена, похожие на секреты (`TOKEN`, `SECRET`, `PASSWORD`, `KEY`, `AUTH` в имени), предлагаются как `kind: 'secret'` с включённым чекбоксом в диалоге подтверждения. Конфликты имён показываются списком: «заменить» / «пропустить» на каждую строку.

# Часть 2. Редизайн попапа расширения

Блок **04 · Расширение** в прототипе. Ширина попапа 340px. Текущие файлы: `extension/popup/popup.html`, `popup.css`, `popup.js`, состояние приходит из `extension/background.js` (`chrome.runtime.sendMessage({type: 'getState'})`).

## Что не так сейчас

- «Перехватывать вкладку» — не сказано, какую: имени и хоста текущей страницы в попапе нет.
- Поле «Порт» занимает столько же места, сколько главный тумблер, хотя его меняют раз в жизни.
- «2 запроса» — единственная живая цифра, и она не кликабельна.
- «Приложение запущено» — надпись без действия; если приложение не запущено, попап ничего не предлагает.

## Приёмка пакета

- Токен в URL подсвечен, по наведению виден подставленный результат и источник; секрет не раскрывается.
- Неизвестная переменная блокирует отправку и предлагает создать себя.
- ⌘E открывает лист, Esc закрывает; после закрытия фокус возвращается в поле URL.
- Prod не редактируется, пока его не разблокировали.
- Окружение создаётся и переименовывается прямо в строке списка; строка не меняет высоту и не сдвигает текст при входе в режим ввода.
- Глобальные видны в таблице каждого окружения; создание одноимённой переменной зачёркивает глобальную с пометкой «перекрыта».
- Секрет раскрывается только глазом в своей строке и снова скрывается при закрытии листа.
- Секреты не появляются ни в экспорте, ни в `localStorage`.
- Попап называет текущую вкладку по имени и хосту; счётчик открывает приложение на этой вкладке.
- При выключенном приложении попап объясняет причину и предлагает запуск; перехват не прекращается.
- Тёмная тема и в приложении, и в попапе.
